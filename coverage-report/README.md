# Coverage report

This folder is where the generated HTML report goes (`index.html`, `Summary.txt`).
It could not be generated when this package was prepared because the .NET SDK was not available.

Generate it from the repository root with `./run-coverage.sh` (Linux/macOS/Git Bash) or `./run-coverage.ps1` (PowerShell),
then commit the resulting `coverage-report/` folder.
